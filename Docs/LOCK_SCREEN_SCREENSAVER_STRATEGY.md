# 锁屏图片播放方案

macOS 不允许普通 App 直接替换锁屏界面，也不能在锁屏层级播放自定义窗口。这是系统安全边界。

可行方案是开发一个独立的 `.saver` 屏保插件，让用户在系统设置里选择它。系统锁屏后如果启用屏保，就能播放 WallhavenWallpaper 已下载的图片。

## 推荐实现

1. 新建 `WallhavenWallpaperScreenSaver.saver`
2. 使用 `ScreenSaver.framework`
3. 读取主 App 的下载目录或共享配置
4. 只播放本地已下载图片，不访问网络
5. 支持 SFW only、NSFW 模糊、间隔、随机/顺序
6. 使用降采样加载图片，避免锁屏时高内存

## 限制

- 不能强制替用户设为系统屏保
- 不能绕过系统锁屏 UI
- App Store 发布会比较麻烦，屏保插件更适合官网分发
- 用户需要手动安装并在系统设置中启用

## 下一步

先把 App 内壁纸墙做好；屏保插件建议作为单独 target 开发，复用图片目录、缓存策略和 NSFW 保护逻辑。
